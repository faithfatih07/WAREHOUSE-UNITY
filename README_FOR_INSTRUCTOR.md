# WAREHOUSE-UNITY

This is the Unity source project for the warehouse environment. It is not a precompiled Windows executable. Windows runtime testing has not been performed.

## Requirements

- Unity Editor **6000.6.10f1**
- Unity Hub

## Open the project

1. Extract `WAREHOUSE-UNITY-Windows-Source.zip` to a folder on your computer.
2. Open Unity Hub and choose **Add** (or **Add project from disk**).
3. Select the extracted project folder, `WAREHOUSE-UNITY`.
4. Open it with Unity Editor 6000.6.10f1 and wait for asset import to finish.
5. In the Project window, open `Assets/Scenes/Warehouse_Final.unity`.
6. Press the Play button to enter Play Mode; press it again to stop.

## Controls

- **WASD** — move in first-person mode
- **Mouse** — camera look
- **V** — switch between overview and first-person camera modes
- **ESC** — release the cursor
- **M** — mute or unmute warehouse audio

The conveyor packages demonstrate flow along a straight conveyor with an endpoint reset. The physical conveyor does not form a closed loop and is not connected to the inspection or packing tables.
